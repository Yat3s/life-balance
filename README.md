## Getting Started

### Prerequisites

- You must be on the **Life Balance developer allow-list**  
- [WeChat DevTools](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html) installed  
- **VS Code** (recommended)  
- **GitHub Copilot** extension (optional, but handy)  

### Development Workflow

1. **Request access** &nbsp;→ message Chris Ye (WeChat ID: 4645643)  
2. **Clone** this repository  
3. **Open** the project in WeChat DevTools and configure your environment  
4. **Create** a feature branch  
5. **Submit** a Pull Request (PR)  
6. After approval, **deploy** and **publish** to WeChat
