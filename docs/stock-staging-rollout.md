# 股票市值修复与体验版部署

## 原因与修复

2026-10-09 排查时，原 Alpha Vantage `OVERVIEW` 接口对现用密钥返回需要付费方案；原实现还同时发起多个请求，触发每秒请求限制。云端 `stockDataCache` 最近成功更新时间为 2026-10-06，旧代码会丢弃非当天缓存，前端失败后不退出加载状态。

新实现通过腾讯行情 `https://qt.gtimg.cn/q=usMSFT,usAAPL,usNVDA,usGOOG` 一次查询四家公司。市值字段和单位对照[腾讯美股页面](https://gu.qq.com/usMSFT)的脚本核实：优先字段 68，回退字段 45，单位为亿美元。云函数保持现有 `B` 单位返回格式，卡片仍显示 `T`。

- `stockFunctions`：独立的新云函数，10 分钟共享缓存；同一实例内合并并发请求。接口失败时可使用 7 天内的完整缓存，并返回原始时间与 `stale` 标记。
- `stockDataCacheV2`：新缓存键。没有新缓存时可读取旧缓存兜底，但不会覆盖旧缓存。
- `stockV2`：12 秒超时、失败提示和点击重试；缓存兜底显示日期；组件移除及超时后忽略晚到结果。
- 校验四家公司数据完整性、价格、市值、币种、涨跌幅和返回格式，避免把无效数据当作有效排名。

该模块仍比较原有的 MSFT、AAPL、NVDA、GOOG 四家公司，不是全市场排名。腾讯行情是公开网页所用接口，没有引入付费凭据；接口格式发生变化时会走校验失败及缓存兜底。
